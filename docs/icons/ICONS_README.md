# Icons and brand assets

The splash uses the full wordmark at `public/leadsghr-logo-v1.svg`. The dark desktop sidebar uses its light-text variant at `public/leadsghr-logo-sidebar.svg`. Smaller UI brand placements use the mark-only `public/logo-leadsghr.svg` and its size-specific SVG variants in `public/`.

The desktop runtime window icon is `apps/desktop/resources/leadsghr-icon.png` (1024 x 1024). The Windows installer/executable uses `apps/desktop/resources/leadsghr-icon.ico`, which includes the standard 16, 32, 48 and 256 px sizes. Run `node scripts/regenerate-brand-assets.mjs` to rebuild the SVG family, then `node scripts/regenerate-brand-icons.mjs` to refresh both desktop icons. The icon files are bundled by `apps/desktop/electron-builder.yml`.

Interface icons are rounded outline SVGs on a 24 px grid in `packages/ui/src/primitives.tsx`. The Crawler sidebar tab uses a spider icon. Navigation, metrics, actions, and status controls use text or accessible labels with icons.

The Profile character avatar is generated by `react-nice-avatar`. Its seed is stored in local browser storage on first creation and replaced only when the user presses **Generate new**. It is not a brand logo.

The LeadsGhr mark shows three white source nodes converging into an open diamond hub, with one violet (`#B66AFF`) output node. Its left-to-right flow represents turning public-source discovery into a lead. The topology and diamond center distinguish it from a radial hub symbol. A dark-purple (`#170927`) rounded tile keeps the mark legible at desktop-icon sizes. The light-background wordmark uses dark-purple `Leads` and purple `Ghr`; the sidebar variant uses white `Leads` and light-violet `Ghr`. Navigation icons are white on the dark rail; dashboard metric icons use purple strokes.
