# Icons and brand assets

The splash uses the full wordmark at `public/leadsghr-logo-v1.svg`. The dark desktop sidebar uses its light-text variant at `public/leadsghr-logo-sidebar.svg`. Smaller UI brand placements use the mark-only `public/logo-leadsghr.svg` and its size-specific SVG variants in `public/`.

The approved transparent LG monogram image is `public/leadsghr-lg-monogram-transparent.png`. `scripts/regenerate-brand-assets.mjs` embeds that image into self-contained SVG variants and wordmarks; run it before `scripts/regenerate-brand-icons.mjs` to refresh the desktop icons. The desktop runtime window icon is `apps/desktop/resources/leadsghr-icon.png` (1024 x 1024). The Windows installer/executable uses `apps/desktop/resources/leadsghr-icon.ico`, which includes standard icon sizes. The icon files are bundled by `apps/desktop/electron-builder.yml`.

Interface icons are rounded outline SVGs on a 24 px grid in `packages/ui/src/primitives.tsx`. The Crawler sidebar tab uses a spider icon. Navigation, metrics, actions, and status controls use text or accessible labels with icons.

The Profile character avatar is generated by `react-nice-avatar`. Its seed is stored in local browser storage on first creation and replaced only when the user presses **Generate new**. It is not a brand logo.

The LeadsGhr mark is an angular purple and deep-purple LG monogram on a transparent background. The light-background wordmark uses dark-purple `Leads` and purple `Ghr`; the sidebar variant uses white `Leads` and light-violet `Ghr`. Navigation icons are white on the dark rail; dashboard metric icons use purple strokes.
